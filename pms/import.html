นำเข้าข้อมูลการจองจากระบบเดิม Bring bookings over from your previous system

แปลงข้อมูลการจองจากโปรแกรมหรือระบบที่เคยใช้ (Excel, CSV, Google Sheet หรือไฟล์ที่ส่งออกจากระบบจองอื่น) ให้เป็นไฟล์ที่แอปพลิเคชัน Saantie PMS นำเข้าได้ ใช้ได้ทั้งบนคอมพิวเตอร์และโทรศัพท์มือถือ

Turn the booking list from whatever you used before — Excel, CSV, Google Sheets or an export from another booking system — into a file the Saantie PMS app can import. Works on a computer or a phone.

ข้อมูลทั้งหมดประมวลผลภายในเบราว์เซอร์ของผู้ใช้เท่านั้น ไม่มีการอัปโหลดหรือส่งข้อมูลลูกค้าไปยังเซิร์ฟเวอร์ใด

Everything is processed inside your browser. Guest data is never uploaded or sent to any server.

เลือกช่วงตารางใน Excel/Google Sheet (รวมแถวหัวตาราง) แล้วคัดลอกมาวางSelect the range in Excel/Google Sheets, header row included, and paste.

ยังไม่มีไฟล์? ดาวน์โหลดตารางตัวอย่างแล้วกรอกข้อมูลตามหัวตารางNo file yet? Download the template and fill in the columns.

2จับคู่คอลัมน์Match the columns

ระบบเดาให้จากชื่อหัวตารางแล้ว ตรวจสอบและแก้ไขเฉพาะช่องที่ไม่ถูกต้อง ช่องที่มี * จำเป็นต้องเลือก

Columns have been guessed from the header names. Check them and fix any that are wrong. Fields marked * are required.

3ตรวจสอบชื่อบ้าน/ห้องCheck room / house names

ชื่อในช่อง “ชื่อในแอปพลิเคชัน” ต้องตรงกับชื่อบ้านหรือห้องที่ตั้งไว้ในแอปพลิเคชัน (ไม่คำนึงถึงช่องว่างและตัวพิมพ์เล็กใหญ่) ชื่อที่ยังไม่มีในแอปพลิเคชัน แอปพลิเคชันจะเสนอให้เพิ่มให้อัตโนมัติตอนนำเข้า หากชื่อเดิมหมายถึงหลายหลัง ให้คั่นด้วยเครื่องหมายจุลภาค เช่น “บ้านเอ, บ้านบี”

The “Name in the app” column must match the room or house names set up in the app (spacing and letter case are ignored). Names the app does not know yet can be added automatically when you import. If one old name covers several units, separate them with commas, e.g. “Villa A, Villa B”.

4ตรวจสอบและสร้างไฟล์นำเข้าReview and create the import file

5นำเข้าในแอปพลิเคชันImport in the app

  1. ส่งไฟล์ .json ที่ดาวน์โหลดไปยังโทรศัพท์ที่ติดตั้งแอปพลิเคชัน (เช่น ส่งผ่าน LINE Keep, Google Drive หรืออีเมล) หากสร้างไฟล์บนโทรศัพท์เครื่องเดียวกัน ไฟล์จะอยู่ในโฟลเดอร์ดาวน์โหลด
  2. Send the downloaded .json file to the phone running the app (LINE Keep, Google Drive or email all work). If you made it on that phone, it is already in Downloads.
  3. เปิดแอปพลิเคชันด้วยบัญชีเจ้าของที่พัก ไปที่ ตั้งค่า → ข้อมูลเก่า → นำเข้าการจองจากไฟล์ แล้วเลือกไฟล์
  4. Sign in to the app as the property owner, go to Settings → Old data → Import bookings from file, and pick the file.
  5. แอปพลิเคชันจะแสดงหน้าตรวจสอบก่อนบันทึก ค้นหาด้วยชื่อ เบอร์โทร ชื่อบ้าน หรือวันที่ เพื่อสุ่มตรวจได้ โดยเฉพาะรายการที่ยังไม่เช็คอิน รายการที่ชนกับการจองที่มีอยู่แล้วในแอปพลิเคชันจะแสดงให้เห็นและจะไม่ถูกนำเข้า ชื่อบ้านหรือห้องที่ยังไม่มีในแอปพลิเคชันจะถูกเพิ่มให้ (ตั้งราคาภายหลังในหน้าตั้งค่า)
  6. The app shows a review screen before saving anything. Search by name, phone, room or date to spot-check the bookings, especially upcoming ones. Bookings that clash with ones already in the app are listed and left out. Rooms the app does not know yet are added for you (set their prices in Settings afterwards).
  7. เมื่อตรวจสอบแล้ว ให้ติ๊กยืนยันรายการที่ยังไม่เช็คอิน แล้วกด “นำเข้า”
  8. Once you are satisfied, tick the box confirming the upcoming bookings and tap Import.
  9. ต้องเชื่อมต่ออินเทอร์เน็ตและเปิดหน้าจอไว้จนนำเข้าเสร็จ การนำเข้าไฟล์เดิมซ้ำจะเขียนทับรายการเดิม ไม่เกิดรายการซ้ำ
  10. Stay online with the screen on until it finishes. Importing the same file again overwrites the earlier copy instead of duplicating it.
